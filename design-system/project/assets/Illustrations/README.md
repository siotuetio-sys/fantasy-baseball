# Illustrations

The baseball mascot, drawn in ink (`line`, #141414) with paper (`bg`, #fbf8f1) and lemon (`pop`, #fff04f) fills. Every file carries its own inks; none inherit colour. All are decorative: use `alt=""` unless the drawing is the only content.

- `mascot-coach.svg` — points up and holds a clipboard. Dashboard hero only, under a speech bubble. 360×300.
- `mascot-pitch.svg` — leg kick with a lemon ball raised. Schedule page mascot. 200×180.
- `mascot-bat.svg` — lemon bat on the shoulder, swoosh lines. H2H page mascot. 200×180.
- `mascot-ice.svg` — lemon ice bag on the cap, wincing eyes, plaster, sweat drops. Injuries and transactions page mascot. 200×180.
- `mascot-head.svg` — the head alone on a lemon ball, a little sleepy. Every empty state, about 92px wide. 120×112.

Page mascots render at 120px wide (84px on phone); keep one drawing per screen besides empty states.

# Toast

A brief confirmation at the bottom center after an action (已加入陣容, 已重新整理).

**Markup:** `div.toast` with one short sentence. The app positions it fixed, 24px from the bottom, and fades it in by 20px.

- `navbg` ground, 1px `accent` border, `on-dark` 13.5px text, `radius-toast`, `shadow-toast`.
- Past tense, names the thing: 「已加入 Aaron Judge 到我的陣容」.

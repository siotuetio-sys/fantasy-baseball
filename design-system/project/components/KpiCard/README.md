# KpiCard

A tappable number with a title and a joke, linking to the page that explains it.

**Markup:** `div.kpis` > `button.kpi` > `b` (the number; add `.hot` when it needs attention), `span` (`span.t` title + `span.s` subtitle) and `span.go` (→).

- `panel`, 1.5px `line`, `radius-kpi`; hover `pop-soft`. Number `kpi-num`; `.hot` turns it `bad`.
- Subtitles are one wry line that still informs: 球場燈都亮了, 有人在冰敷就會亮紅燈.

# StatTile

A quiet number-and-label tile for stat grids inside a card.

**Markup:** `div.statbox` > `div.stat` > `div.v` + `div.k`.

- `panel` with a `border` hairline (not ink), `radius-tile`. Value `stat-num`; key `caption` `muted`. Tint the value with `.tag-good` / `.tag-bad` when it beats or trails the league.

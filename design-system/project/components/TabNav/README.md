# TabNav

The seven views as pill tabs; a bottom tab bar under 680px.

**Markup:** `nav.tabs` > `button` with an icon (`.ic` > `svg.ico`) and a `.lb` label; the current view gets `.active`. Add `.bottom` for the phone bar.

- Top: transparent pills with ink text; hover draws the outline; active is an ink pill with paper text.
- Bottom: equal tabs 52px tall, label 10px; the active tab sits on a lemon tile. Pad by the bottom safe area.

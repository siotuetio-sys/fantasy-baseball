# Button

Filled orange primary button and grey ghost button.

**Markup:** `button.btn` (primary) or `button.btn.ghost` (secondary). Label is a verb phrase: 分析今日先發, 載入戰績, 清空.

- Primary: `accent` fill, `on-dark` label 13px/700, `radius-btn`, padding 9px 15px. White on accent is 3.12:1 — keep the label bold.
- Ghost: `panel2` fill, 1px `border`, `text` label.
- Hover brightens 8%; press scales to 0.97; focus shows the 2px `accent2` outline.
- One primary per card; secondary loads (載入戰績, 分析本週) are ghost.

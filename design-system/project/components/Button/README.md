# Button

Ink pill for the main action, paper pill for the rest.

**Markup:** `button.btn` or `button.btn.ghost`. Labels are verbs, and may be playful when the action is obvious: 叫球員報到, 再揮一次.

- Primary: `text` fill, `bg` label, 13px/700, `radius-pill`. Ghost: `panel` with an ink outline; hover `pop-soft`.
- One primary per card.

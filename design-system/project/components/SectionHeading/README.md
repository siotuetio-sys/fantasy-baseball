# SectionHeading

Heading for a view or a card, with an optional grey pill for context (date, source, count).

**Markup:** `h2.sec` with text and an optional `span.pill`. Inside a card set `margin:0` (or `margin-top:0`). For a group label above a list use `div.seclabel`.

- `section` style, `text` color; pill 11px/600 `muted` on `chip`, `radius-pill`.
- Lead a card heading with one emoji; a view heading has none.
- Use a `·` to add a subtitle: 「⭐ 我的球員 · 今日先發建議」.

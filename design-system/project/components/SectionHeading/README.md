# SectionHeading

Page and card headings in the serif, with an English sticker label and an optional grey pill.

**Markup:** `h2.sec.page` for a page title, `h2.sec` for a card title; then `span.sticker` (the English label) and `span.pill` (date, source, count).

- `page-title` 28px or `card-title` 19px in `head`, ink. Label in `sticker`: uppercase DM Mono in an ink-outlined pill. Pill 11px on `chip`.
- Name pages with a question or nickname (今天誰跟誰打, 球員顯微鏡); keep the label to two or three English words. No emoji.

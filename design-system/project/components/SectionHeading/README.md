# SectionHeading

Page and card headings in the serif, with a handwritten English aside and an optional grey pill.

**Markup:** `h2.sec.page` for a page title, `h2.sec` for a card title; then `span.hand` (the aside) and `span.pill` (date, source, count).

- `page-title` 28px or `card-title` 19px in `head`, ink. Aside in `hand`, `muted`, 1.25em. Pill 11px on `chip`.
- Name pages with a question or nickname (今天誰跟誰打, 球員顯微鏡); keep the aside to two or three English words. No emoji.

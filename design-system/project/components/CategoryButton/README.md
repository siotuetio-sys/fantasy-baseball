# CategoryButton

Green pill naming a fantasy category to attack, used in the H2H strategy rows.

**Markup:** a `div.stratrow`-style line: a bold label, then `button.catbtn` per category (HR, SB, K…).

- `good-bg` fill, `good` text and 1px `good` border, `radius-pill`, 12px/700; press scales to 0.95.
- The label before the pills says the action (主攻, 守住) so color is never the only cue.
